# mylinks

Gestor de bookmarks simple, sin dependencias, pensado para GitHub Pages.

## Funcionalidades

- Añadir, editar y eliminar enlaces
- Búsqueda por título/URL y filtro por etiquetas
- Modo oscuro
- Exportar/importar en JSON

## Uso local

Abre `index.html` en el navegador, no requiere build ni servidor.

## Deploy en GitHub Pages

1. Sube este repo a GitHub.
2. En Settings → Pages, elige la rama `main` y carpeta raíz `/`.
3. La app quedará en `https://<usuario>.github.io/<repo>/`.
